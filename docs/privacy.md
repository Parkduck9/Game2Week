# 《닿을 때까지》 개인정보 처리방침

시행일: 2026년 10월 13일 · 게시자: NIPAD

《닿을 때까지》(이하 "게임")는 이용자의 개인정보를 수집, 저장, 이용하거나 제3자에게 전송하지 않습니다.

## 1. 수집하는 개인정보
게임은 이름, 이메일, 전화번호, 위치, 연락처, 사진 등 **개인을 식별할 수 있는 정보를 수집하지 않습니다.** 회원가입이나 로그인 기능이 없으며, 채팅·광고·인앱 결제 기능도 없습니다.

## 2. 이용자 기기에만 저장되는 정보
게임 진행을 위해 다음 정보가 **이용자의 PC 안에만** 저장됩니다. 이 정보는 외부로 전송되지 않습니다.
- 게임 진행 기록 (해금한 스테이지, 최고 기록)
- 게임 설정 (음량, 화면 모드·해상도, 텍스트 속도)

게임을 삭제하면 이 정보도 함께 삭제됩니다. Windows의 앱 데이터 백업 설정을 켠 경우, Windows가 이 정보를 이용자의 Microsoft 계정(OneDrive)에 백업할 수 있습니다. 이는 Microsoft의 개인정보 처리방침을 따릅니다.

## 3. 게임 엔진의 기술 정보
게임은 Unity 엔진으로 제작되었습니다. Unity 엔진은 엔진 개선을 위해 운영체제 버전, 그래픽 장치 종류 같은 **익명의 기술 정보(하드웨어 통계)** 를 Unity Technologies에 보낼 수 있습니다. 이 정보에는 이용자를 식별하는 정보가 포함되지 않으며, 게시자는 이 정보를 받거나 이용하지 않습니다. 자세한 내용은 [Unity 개인정보 처리방침](https://unity.com/legal/privacy-policy)을 참고하세요.

## 4. 아동의 개인정보
게임은 연령과 관계없이 어떤 개인정보도 수집하지 않습니다.

## 5. 방침의 변경
이 방침이 바뀌면 이 페이지에 바뀐 내용과 시행일을 게시합니다.

## 6. 문의
개인정보 처리방침에 관한 문의는 Microsoft Store의 《닿을 때까지》 페이지에 있는 지원 연락처로 보내 주세요.

# Privacy Policy — "Until I Reach You" (닿을 때까지)

Effective date: October 13, 2026 · Publisher: NIPAD

The game does **not collect, store, use, or transmit any personal information.** There is no account, login, chat, advertising, or in-app purchase.

- **Stored only on your device:** game progress (unlocked stages, best records) and settings (volume, display mode/resolution, text speed). This data is never sent anywhere and is removed when the game is uninstalled. If Windows app-data backup is enabled, Windows may back it up to your Microsoft account (OneDrive) under Microsoft's privacy policy.
- **Game engine:** The game is built with the Unity engine, which may send anonymous technical information (such as OS version and graphics device type) to Unity Technologies. It contains no personally identifying information, and the publisher does not receive or use it. See the [Unity Privacy Policy](https://unity.com/legal/privacy-policy).
- **Children:** The game collects no personal information from anyone, regardless of age.
- **Changes:** Any changes will be posted on this page with a new effective date.
- **Contact:** Please use the support contact on the game's Microsoft Store page.
