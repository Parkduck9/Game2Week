# 작업량 기록 — 사람 기준

> **사람 기준 시간** = 중급 Unity 개발자 1명이 같은 결과(코드 + 테스트 + 문서)를 직접 만들 때 걸릴 것으로 보는 시간. 8시간 = 1일.
