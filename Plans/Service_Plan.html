서비스 흐름 · Microsoft Store 배포 계획

2026-10-06 · 목표: 메인 → 스테이지 선택 → 전투(일시정지) → 결과 → 엔딩 → 메인, 진행·설정 저장, Microsoft Store 설치·삭제까지

✔ 확정된 결정

  • 스토어: Microsoft Store — MSIX 패키지. 회사에선 빌드·패키징 준비까지, 집에서 로컬 설치(사이드로드)·삭제 확인 → 파트너 센터 제출
  • 최고기록 = 클리어 시간 + 결과 종류 (처치 / 살려줌) — 스테이지별 가장 빠른 시간
  • 설정: 음량(배경음/효과음) · 화면 모드·해상도 · 텍스트 속도
  • 삭제하면 세이브도 사라짐 — 껐다 켜도 진행·설정은 남고, 앱을 제거하면 함께 지워짐 (스토어 앱 기본 동작)

메인 화면

  • 새로 시작 — 세이브가 있으면 "진행이 지워져요" 확인 → 진행 초기화(설정은 유지) → 스테이지 선택
  • 이어하기 — 세이브가 없으면 회색(선택 불가) → 스테이지 선택
  • 설정 — 설정 화면 (메인·일시정지 어디서든 같은 화면)
  • 종료

스테이지 선택

  • 해금된 스테이지만 표시: 1번은 처음부터, N번을 클리어하면 N+1번 해금
  • 각 줄: 번호 · 이름 · 최고기록(시간) · 결과 아이콘(처치/살려줌) · 미클리어 표시
  • 취소키 → 메인

일시정지 (전투 중 ESC)

  • 시간 정지 + 어두운 화면 + 계속 / 설정 / 메인으로
  • 메인으로: "이번 전투 진행은 저장되지 않아요" 확인
  • 일시정지 중 시간은 클리어 시간에 포함 안 됨

결과 · 엔딩

  • 승리: 클리어 시간 표시, 신기록이면 "신기록!" → 저장
  • 메뉴: 다음 스테이지(있으면) · 다시 도전 · 스테이지 선택
  • 마지막 스테이지를 처음 클리어하면 엔딩 화면(임시 문구·크레딧) → 메인
  • 패배: 다시 도전 · 스테이지 선택

2저장 (세이브)

Application.persistentDataPath에 JSON 두 개 — 진행(save.json)과 설정(settings.json)을 분리해서, 새로 시작해도 설정은 남게 합니다.

save.json
{
  "version": 1,
  "stages": [ { "id": "stage_001", "cleared": true, "bestTimeSeconds": 41.3, "bestOutcome": "EnemySpared" } ],
  "endingSeen": false
}
settings.json
{ "version": 1, "bgmVolume": 0.8, "sfxVolume": 0.8, "fullscreen": true, "resolution": "1920x1080", "textSpeed": "normal" }
  • 쓰기: 임시 파일에 쓴 뒤 교체 (저장 도중 꺼져도 파일이 깨지지 않게) + 직전 파일 .bak
  • 읽기 실패(깨짐·버전 다름) → .bak 시도 → 그래도 안 되면 새로 시작 (로그 남김)
  • 해금은 저장하지 않고 계산: "클리어한 스테이지 다음 하나까지" — 스테이지가 추가돼도 자연스럽게 열림
  • 삭제 시 함께 제거: MSIX 앱이 AppData에 쓰는 파일은 패키지 전용 폴더로 옮겨 저장되고, 앱을 제거하면 같이 지워짐 → 집에서 실제로 확인

3구현 단계

S1. 세이브·설정 저장소 Claude

SaveData/SettingsData, 원자적 쓰기 + 백업, 해금 계산, 최고기록 갱신 규칙 + 테스트

S2. 메인 화면 개편 + 설정 화면 Claude

새로 시작(덮어쓰기 확인) · 이어하기(세이브 없으면 비활성) · 설정 · 종료. 설정: 좌우키로 값 변경, 즉시 적용(해상도·전체화면), 음량은 오디오 믹서 연결만 준비

S3. 스테이지 선택 Claude

해금된 스테이지 목록, 최고기록·결과 아이콘, 선택 → 전투

S4. 일시정지 + 클리어 시간 Claude

Input에 Pause(ESC) 추가, 시간 정지, 계속/설정/메인으로. 전투 시간 측정(일시정지 제외)

S5. 결과·엔딩 Claude

결과 화면에 시간·신기록, 다음 스테이지, 엔딩 씬(임시 문구) → 메인. 전체 흐름 PlayMode 테스트(진행이 저장되고 다시 켰을 때 남아 있는지)

S6. 출시 준비 Claude

Player Settings(회사·제품 이름, 버전, 임시 아이콘), 배치모드 Windows 빌드 스크립트, MSIX 포장용 AppxManifest.xml 템플릿 + Tools/package_msix.ps1, 집에서 할 일 안내서(Plans/Store_Guide)

S7. 집에서: 설치·삭제 확인 사용자

  • Windows SDK 설치(makeappx, signtool), 개발자 모드 켜기
  • 테스트 인증서로 서명 → 더블클릭 또는 Add-AppxPackage로 설치 → 실행·진행 저장 확인
  • 설정 ▸ 앱에서 제거 → 세이브 폴더가 지워졌는지 확인 → 다시 설치하면 처음부터인지 확인

S8. 집에서: 스토어 제출 사용자

  • 파트너 센터 개발자 계정, 앱 이름 예약 → 예약된 게시자 정보로 매니페스트 갱신(Claude가 도움)
  • 스토어 등록 정보(설명·스크린샷·연령 등급·개인정보 처리방침 URL) 작성 → 제출 → 심사
  • 스토어에서 설치 · 삭제 확인

4알아 둘 것

집에서 꼭 사용자가 해야 하는 것

  • 파트너 센터 계정 가입·결제·앱 이름 예약, 인증서 신뢰 설정, 스토어 제출은 계정과 결제가 필요해서 직접 하셔야 해요.
  • 스토어 심사에는 개인정보 처리방침 URL·연령 등급 설문이 필요해요 (세이브는 로컬만 쓰므로 수집 정보 없음으로 작성 가능).
  • 게임 이름(지금 "타이틀 (가제)")과 아이콘은 제출 전에 정해야 해요 — IP 기획과 연결.

기존 계획과의 순서

S1~S5(서비스 흐름)는 전투 내용과 독립적이라 지금 바로 진행 가능. 07(타이밍 공격)·09(탄막 패턴)는 전투 재미 부분이라 병행하거나 뒤에. S6(출시 준비)은 게임 이름이 정해진 뒤가 좋아요.
