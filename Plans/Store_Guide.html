집에서 할 일 — 설치·삭제 확인 → Microsoft Store 제출

S7·S8 안내서 · 명령은 모두 프로젝트 폴더(Game2Week)에서 PowerShell로 실행

1. 준비2. 빌드·포장3. 설치4. 확인5. 삭제6. 스토어 제출문제 해결

1준비 (한 번만)

  1. 프로젝트 받기 — GitHub Desktop에서 Parkduck9/Game2Week Clone (또는 git clone https://github.com/Parkduck9/Game2Week.git)
  2. Unity Hub 설치 → Installs ▸ 6000.3.25f1 설치 (모듈: Windows Build Support (IL2CPP)는 선택, 기본 Mono로도 빌드됨)
  3. Windows SDK — makeappx.exe·signtool.exe가 필요해요. Visual Studio Installer ▸ 개별 구성 요소 ▸ "Windows 11 SDK" 또는 Windows SDK 단독 설치 파일
  4. Unity Hub에서 프로젝트를 한 번 열어 임포트가 끝나면 에디터를 닫기 (열려 있으면 빌드 스크립트가 못 돌아요)

2빌드 · 테스트용 패키지 만들기

powershell -ExecutionPolicy Bypass -File Tools/build_windows.ps1 -Version 0.1.0
powershell -ExecutionPolicy Bypass -File Tools/package_msix.ps1 -Version 0.1.0.0 -CreateTestCert
  • 결과: Builds/Msix/Game2Week.Dev_0.1.0.0_x64.msix + 테스트 인증서 Builds/Msix/TestCert.cer
  • 패키지 버전은 a.b.c.d 네 자리. 다시 설치할 땐 숫자를 올리거나 먼저 삭제

3설치

  1. 테스트 인증서 신뢰 (처음 한 번, 관리자 PowerShell): 
    Import-Certificate -FilePath "Builds\Msix\TestCert.cer" -CertStoreLocation Cert:\LocalMachine\TrustedPeople
  2. .msix 파일 더블클릭 → 설치 (앱 설치 관리자). 또는 
    Add-AppxPackage "Builds\Msix\Game2Week.Dev_0.1.0.0_x64.msix"
  3. 시작 메뉴에 "타이틀 (가제)"가 생기면 성공

4확인 체크리스트

  • 시작 메뉴에서 실행 → 메인 화면, 이어하기가 회색
  • 새로 시작 → 1-1 클리어 → 결과에 클리어 시간·신기록
  • 엔딩까지 보고 메인 → 게임 종료
  • 다시 실행 → 이어하기 활성, 스테이지 선택에 최고기록이 남아 있음
  • 설정에서 텍스트 속도·화면 모드 변경 → 종료 후 다시 실행해도 유지
  • 전투 중 ESC → 일시정지 → 계속 / 메인으로
  • 세이브 위치 확인: 
    Get-AppxPackage Game2Week.Dev | Select-Object PackageFamilyName
explorer "$env:LOCALAPPDATA\Packages"
    → Game2Week.Dev_… 폴더 안 LocalCache\LocalLow\DefaultCompany\Game2Week\save.json 이 있으면 정상 (패키지 앱의 AppData 쓰기는 이 폴더로 옮겨짐)

5삭제 → 세이브도 지워지는지

  1. 설정 ▸ 앱 ▸ 설치된 앱 ▸ "타이틀 (가제)" ▸ 제거 (또는 Get-AppxPackage Game2Week.Dev | Remove-AppxPackage)
  2. %LOCALAPPDATA%\Packages\Game2Week.Dev_… 폴더가 없어졌는지 확인
  3. 다시 설치 → 실행 → 이어하기가 회색(처음부터)이면 "삭제하면 세이브도 사라짐" 확인 완료
  4. 테스트가 끝나면 인증서 정리 (관리자): 
    Get-ChildItem Cert:\LocalMachine\TrustedPeople | Where-Object Subject -eq "CN=Game2Week Dev" | Remove-Item
Get-ChildItem Cert:\CurrentUser\My | Where-Object Subject -eq "CN=Game2Week Dev" | Remove-Item

6Microsoft Store 제출

제출 전에 정해야 할 것: 게임 이름(지금 "타이틀 (가제)"), 아이콘(Tools/msix/Images/에 PNG 4종을 넣으면 임시 로고 대신 사용), Unity 회사 이름(세이브 경로에 들어가므로 출시 후엔 바꾸기 어려움).
  1. 파트너 센터(partner.microsoft.com) 개발자 계정 가입 — 개인/회사 선택, 본인 확인
  2. 앱 및 게임 ▸ 새 제품 ▸ MSIX or PWA 앱 ▸ 이름 예약
  3. 제품 관리 ▸ 제품 ID에서 세 값 복사: Package/Identity/Name, Package/Identity/Publisher, Package/Properties/PublisherDisplayName
  4. 그 값으로 서명 없이 포장 (스토어가 서명): 
    powershell -ExecutionPolicy Bypass -File Tools/package_msix.ps1 -Version 1.0.0.0 -NoSign `
  -Name "<Identity/Name>" -Publisher "<Identity/Publisher>" -PublisherDisplayName "<PublisherDisplayName>" -DisplayName "<예약한 이름>"
    버전 마지막 자리는 0, 제출할 때마다 앞자리를 올려요.
  5. 제출 항목 작성: 가격·지역, 속성(카테고리: 게임), 연령 등급(IARC 설문), 패키지 업로드, 스토어 목록(설명, 스크린샷 — Reference/store_screenshot.png 1920×1080 사용 가능), 개인정보 처리방침(세이브는 기기에만 저장, 수집 정보 없음)
  6. 제출 → 인증 심사 → 게시되면 스토어에서 설치 → 실행 → 삭제까지 확인

!문제 해결

  • "신뢰할 수 있는 인증서가 아님" / 0x800B0109 — 3-1의 인증서 신뢰를 관리자 권한으로 했는지 확인
  • "이미 설치된 패키지보다 버전이 낮음" — 버전을 올리거나 먼저 삭제
  • makeappx 를 찾을 수 없음 — Windows SDK 설치 (1-3)
  • 빌드 스크립트가 바로 실패 — Unity 에디터가 이 프로젝트를 열고 있음 → 닫고 다시
  • 스토어 업로드 시 Publisher 불일치 — 4번 명령의 값이 제품 ID 화면과 글자 하나까지 같은지 확인
